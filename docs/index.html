Claude Code 플러그인 · my-kit 0.1.0

oss-review-kit

검토 주제만 주면 공개 오픈소스 후보를 찾아 DeepWiki로 확인하고, 근거 검토를 거친 도입 검토 리포트와 도입 기획안까지 만들어 주는 Claude Code 플러그인입니다.

어떻게 동작하나요

주제 입력

예: 프롬프트 자동 최적화 프레임워크. 저장소를 함께 줘도 됩니다.

후보 찾기

모델 지식 후보와 대표 저장소(허브) 위키에서 언급된 저장소를 모읍니다.

DeepWiki 확인

후보마다 위키가 실제로 있는지 확인하고, 확인된 것만 보여 줍니다.

조사와 초안

조사 agent가 구조, 연동, 보안, 버전, 운영 고려사항을 모읍니다.

근거 검토

검토 agent가 PASS·WARN·FAIL을 매기고, FAIL이면 고친 뒤 다시 검토합니다.

명령 만들어 보기

플러그인은 Claude Code 안에서 실행됩니다. 이 칸은 웹에서 바로 실행하지는 않고, Claude Code 세션에 붙여 넣을 명령을 만들어 줍니다.

① 도입 검토 리포트


      
② 기획안 (리포트가 만들어진 뒤)

      

    

  


  

    
실제 결과 예시 (2026-11-17)

    
주제 "프롬프트 자동 최적화 프레임워크"만 넣었을 때 후보 4개(stanfordnlp/dspy, gepa-ai/gepa, zou-group/textgrad, microsoft/PromptWizard)가 모두 DeepWiki에서 확인됐고, gepa-ai/gepa는 모델 지식과 DSPy 위키 양쪽에서 잡혀 추천됐습니다.

    

      
결과물내용검토 이력

      

        도입 검토 리포트
gepa-ai/gepa		
        도입 권고 "조건부". 주제 적합성은 높고, 평가 코드 격리와 키 관리는 확인되지 않아 통제 조건이 필요하다는 결론
        FAIL → 수정 → WARN
      

      

        도입 기획안
사내 문서 추출 프롬프트 자동 최적화		
        비식별 평가 세트, 필드별 평가 함수, 사내 호스팅 모델 우선, 파일럿부터 시작하는 구조. 목표 수치는 근거가 없어 파일럿 기준선 측정 후로 미룸
        FAIL → 수정 → PASS
      

    

    

      GEPA 도입 검토 리포트 (웹 보고서) →
      GEPA 도입 검토 리포트 (md 원본) →
      사내 문서 추출 프롬프트 자동 최적화 도입 기획안 (md) →
    

    
예시의 근거는 모두 AI가 생성한 DeepWiki 자료입니다. 도입을 결정하기 전에는 원 저장소와 공식 문서로 다시 확인해야 합니다.

  


  

    
설치

    
Claude Code 세션에서 차례로 실행합니다.

    
/plugin marketplace add puttylike/oss-review-kit
/plugin install my-kit@capstone-local

    
플러그인에 넣을 수 없는 설정은 업무 폴더의 .claude/settings.json에 둡니다. 키나 토큰은 필요 없습니다.

    
{
  "permissions": {
    "deny": ["WebSearch", "Read(~/.claude.json)", "Read(~/.config/gh/**)"]
  },
  "allowedMcpServers": [
    { "serverUrl": "https://mcp.deepwiki.com/mcp" }
  ]
}

    
훅 스크립트는 jq가 필요합니다. jq가 없으면 fail-closed 설계에 따라 도구 호출이 막힙니다.

막는 것

        
    
          
  • mcp.deepwiki.com 밖으로 나가는 Bash·WebFetch 호출 (net-guard)
    • 
          
  • deepwiki가 아닌 MCP 도구와 쓰기 성격 도구 (mcp-guard)
    • 
          
  • 훅 스크립트가 없거나 깨지면 기본 차단 (onFailure: block)
    • 
          
  • 웹 검색, 인증 파일 읽기 (폴더 deny 규칙)
    •
